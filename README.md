# Irish Practice Apps

*Cleachtadh Gaeilge*

Irish is a beautiful language with a rich history and a living cultural tradition. Learning it offers a way to connect with its literature, music, people, and everyday expressions.

## About this project

Irish Practice is a free collection of small, standalone browser-based activities designed to support learners of Irish (*Gaeilge*). Its purpose is to provide opportunities to:

- Reinforce selected aspects of Irish grammar, including verb forms, mutations, sentence structure, and the use of prepositions.
- Practise common vocabulary, numbers, and expressions.
- Build familiarity and confidence through short, repeatable exercises and quizzes.

The activities are intended as a supplement to classes, conversation, reading, and other learning resources, rather than as a complete Irish course. They cover selected topics and may not account for every dialectal variation or grammatical exception.

## Getting started

1. Download the project and extract the ZIP file into a folder, or clone the repository.
2. Open `index.html` in a web browser (for example, by double-clicking it).
3. Choose an activity from the main page. You can switch the main page between English and Irish.

The collection is designed to run locally without an internet connection or a web server.

## Feedback and corrections

These activities may contain bugs, language errors, omissions, or other oversights. If you encounter a problem, please [raise an issue on GitHub](https://github.com/concipio-info/Irish-Practice/issues). Reports of incorrect Irish, unclear questions or explanations, and suggestions for additional exercises are especially welcome. Where possible, include the activity name, the question or wording involved, and what you expected to happen.
