Quick grammar guide & reference

These exercises use standard written Irish. For quantities above nineteen, the model answer uses the established “units + noun + is + tens” pattern. The standard simplified pattern is also accepted. Ordinal prompts include “the”: include an in your answer.

ContextPattern / example
Counting alouda haon, a dó, a trí, a ceathair; fiche a dó
Before a noundhá bhád; ceithre bhád
Most nouns, two–sixLenition; usually a singular noun.
Seven–tenEclipsis: seacht mbád, ocht n-úll.
Special counting formstrí bliana; seacht mbliana; trí cinn
TeensNoun between the numbers: dhá bhád déag. After a vowel-ending singular noun use dhéag; special counting plurals retain déag.
Firstan chéad bhád; an chéad teach
Other ordinalsConsonants unchanged; prefix h to a vowel-initial noun: an dara húll.
Compound ordinalsan tríú bád déag; an tríú bád is fiche

One hundred is céad; the hundredth is an céadú. First uses an chéad.

Scope: standalone cardinals zero–one hundred; quantities one–ninety-nine; ordinals first–hundredth. Twelve nouns cover ordinary mutations, vowel prefixes, and special counting plurals. Personal numbers, adjective agreement, and genitive constructions are outside this practice set. Accepted variants are listed after checking; the checker is not a general Irish grammar parser.

Grammar reference: An Caighdeán Oifigiúil, chapter 9. Dictionary: Teanglann. These optional links need internet; practice does not.
